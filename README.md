# Lucky Club — 單機 + 多人連線版

沿用原本的銀灰街機、轉盤、花朵、跟隨眼睛、音效、Word Burst 與單機穿搭卡下載；新增**真正跨裝置即時同步**的多人房間。

## 怎麼玩

1. 打開網站，切換「多人連線」。一位玩家輸入暱稱與至少 4 碼的房間密碼，按「建立密碼房間」。
2. 房主將「複製邀請」的房間網址傳給朋友，並**另行告訴朋友密碼**（密碼不會出現在連結裡）。
3. 所有人進房後，都會拿到不同的代表色。房主在 2～12 人到齊後按「房主開始」。
4. 所有裝置同步看到「3、2、1、GO!」砸落倒數，每個畫面約 0.75 秒。
5. 每局依序抽選 **主題 → 配色 → 小物**。每一個項目每人只能按一次 SPIN，**全部人完成才統計票數**。抽完的人會看到等待訊息。
6. **每人一票，所有人獨立均勻隨機抽選**，不採用任何同頻加成。最高票若只有一個選項，就成為該項目的穿搭規則；最高票平手時**所有人重新抽該項**，直到出現唯一的最高票選項。
7. 三項全部確定後，顯示與單機同風格的票卡，所有人都可複製結果或下載高清 PNG 穿搭小卡。房主可以準備下一局。

### 公平規則

房主只能控制開始與下一局，不能指定轉盤結果或跳過其他玩家。每人每輪只有一次機會，系統等全員完成才開放下一輪。轉盤動畫約 0.65 秒，倒數 3、2、1、GO! 仍保留。

## 本機執行

需要 **Node.js 20 或更新版**。伺服器沒有任何第三方 npm 套件。

```bash
npm start
```

開啟 `http://localhost:3000`。同一 Wi-Fi 的其他裝置可連線至該電腦的區網 IP 與 3000 埠（需要電腦允許連線）。

## 真正公開發佈（推薦 Render Web Service）

原本 Netlify Drop 靜態網站不能單獨提供同步多人房間。需要**執行 Node.js 的網路伺服器**。

1. 將此 ZIP 解壓，將資料夾中的 `server.js`、`package.json`、`render.yaml`、`public/` 等檔案放在 GitHub repository **根目錄**並推送。
2. 登入 [Render](https://dashboard.render.com/)，選 **New → Web Service**，連接該 GitHub repository。
3. Build Command：`npm install`；Start Command：`npm start`。可依需求選用 Free；程式會自動監聽 Render 的 `PORT`。
4. 發佈完成後會取得 `https://...onrender.com` 網址。**同一個網址**同時提供單機和多人模式，把網址傳給朋友即可。

**注意：** 免費 Render Web Service 閒置約 15 分鐘後會休眠，醒來可能要一小段時間。房間目前保存在伺服器記憶體中，**伺服器重新啟動／重新部署會使現有房間失效**，必須重開。此設計適合朋友即興同玩，不適合長時間保留房間或高可用的商用服務。房間最多 12 人、2 小時未活動會清理，離線超過約 90 秒會退出以免卡住配對。

## 技術與安全

- 單一 Node HTTP 伺服器提供靜態檔案、房間 API 與 **Server-Sent Events (SSE)** 即時推播。
- 服務端以 `crypto.scryptSync` 雜湊保存密碼、使用定時比較驗證。每人透過 `HttpOnly`、`SameSite=Lax` session cookie 驗證操作，房主權限和選項鎖定都在伺服器檢查。
- 房間代碼使用密碼安全隨機亂數生成；密碼不會儲存到網址、瀏覽器 localStorage 或即時狀態資料。
- 題庫與自製 SVG 圖示延續原版；單機版不使用網路 API，仍能在伺服器上當作單人遊戲使用。
- 完整套件已包含 favicon、Apple Touch Icon。
- 若未來希望**房間在伺服器重啟後仍存在**，需另加資料庫或專門的房間儲存服務。目前未實作。

## 重要檔案

- `server.js` — 建房、密碼、SSE、房主開始、抽選、比對、鎖定、離線處理
- `public/index.html` — 原單機版 + 新多人介面 + Number Slam 動畫
- `public/multi.js` — 多人前端、代表色、單一轉盤、共享結果
- `public/catalog.json` — 單機與多人使用相同題庫
- `render.yaml` — Render Web Service 設定
